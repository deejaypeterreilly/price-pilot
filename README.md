# Price Pilot

Price pilot is a fullstack web application, used for comparing online prices of products.

## Tech Stack

- **Frontend:** React, Vite, JavaScript
- **Backend:** Node.js, Express
- **Database:** PostgreSQL
- **Version Control:** Git and GitHub

## Project Structure

- `client/` — React frontend
- `server/` — Express backend
- `.gitignore` — Files and directories excluded from version control

## Development Status

Currently in development. The initial focus is establishing the project structure, configuring the backend, and connecting the frontend to the API.

## Planned Features

- Product watchlist
- Price history and charts
- Target-price alerts
- User authentication
- Dashboard and notifications

Setup instructions will be added as the frontend, backend, and database configuration are completed.
